# Monte-Carlo-Simulation-of-Completion-Times
This repository holds my work oon the prediction of uncertainty using Monte Carlo simulations
My fascination with how uncertainty is predicted has only grown since completing my undergraduate programme in Actuarial Science.
This project shows the power of mathematical models like Monte Carlo Simulation. The project also shows how this model is used to calculate the probabilities of uncertain events happening.
The Monte Carlo simulation is very powerful and has a varied use in fields such as finance, stock pricing and trading, risk analysis, buffer allocation in construction and insurance.
This project shows the typical application of the monte carlo simulation in finding the probability of completing a set of reports on time before a meeting.
